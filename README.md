# 1 RUPEE KAAM KA — Starter PWA

## Run locally
Open `index.html` in a modern browser. For install/offline PWA features, host the folder on an HTTPS static host (for example GitHub Pages, Netlify, or your own domain).

## Included
- EMI calculator
- Monthly budget balance
- Discount calculator
- Bill splitter
- Unit-price comparison
- GST add-on calculator
- Age calculator
- Simple CTC estimate
- Electricity cost estimate
- Device-local task saver
- English, Hindi, Marathi UI
- Responsive mobile-first layout

## Important launch limitations
This is a working front-end prototype, not a live paid product.
- No payment gateway is connected.
- Do not show a "payment successful" state without server-side payment verification.
- ₹1 pricing needs gateway fee/minimum-transaction review; processing fees can exceed the sale price.
- The checklist is stored only on the visitor's device.
- CTC, GST, tax and electricity outputs are estimates; publish jurisdiction-specific disclaimers and validate formulas before commercial use.
- No customer accounts, analytics, admin panel, or cloud sync are included.
